# 双配色导出历史案例（匿名）

原案例含袋、盒、横卡与竖卡四类原图，采用两档古风配色。包装无框，上沿开启、光效包裹全身，各1秒；卡牌完整亮相再翻走，残留动态云气框，各3秒。这是历史输入，不是新项目默认值。

早期某个卡牌源含烘焙包装；局部遮罩补框不等于无损分离。配准缓存来自真实动态源，不应用静态图伸缩替代，也不要复制大体积缓存到skill。项目路径、源任务ID、源文件哈希和获准配色版本均从主题私有档案读取。

历史预览曾为单侧384×480、左右768×480，正式交付按原图重合成到单侧1068×1334、打包2136×1334、30fps、H264、单条小于5MB。生成源仍为当时约定的480p；大画布不等于原生高清，正式与否按内容认可确定。

软件与同机指定硬解结果一致、PTS连续时，用户仍曾报告阶梯破图。随后制作全I帧兼容版本，但未得到用户端解决确认。因此技术结果不等于兼容根因闭环，也不能替代目标客户端Alpha/RGB混合验收。通用媒体诊断用本skill的fx_media.py；历史脚本路径和固定目录深度不带入新主题。
