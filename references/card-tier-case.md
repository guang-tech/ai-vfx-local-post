# 三档拆卡历史案例（匿名）

这是一个历史版本的认可快照，不代表任何项目当前最新交付。实际项目入口、版本与认可原话保存在主题私有记录；本公开案例只保留通用经验。某些开包动作在当时已获接受，不应因早期描述不同自动返修；目标客户端混合未独立确认的状态仍须保留。

交付示例为HTML、8条AlphaRGB及1条直播透明MOV。继承画布为左右2136×1334、单侧1068×1334、30fps、H264 yuv420p、每条MP4小于5MB；横卡宽623、竖卡428、袋426、盒501。该批另改卡牌为2秒/60帧，包装1秒/30帧；直播为540×960、24fps、4秒。这些数字只属于该案例，不是默认规格。

|档位|爆发语言|素材关系|
|---|---|---|
|高卡|冰蓝/紫罗兰与暖金星屑，短促释放|虹彩饰件与粉色小元素；有连接关系的主体组合固定|
|编卡|冰晶、电光和速度碎片|带环饰件与银色小元素|
|顶编|金色烟花、暖金星屑与爱心|晶体饰件与金色小元素|

修订去掉花朵、宽蝶翼环线和刚性直线，保留爆发后轻薄流动丝光。横竖爆发与持续框分别适配；其中一档持续框由本主题另一源片本地改色，不能称作全部独立生成。

依赖可能跨同一主题的早期版本：开包金光、盒体动作、直播源片分别保留不同旧版本文件。因此按依赖清单清理，而不是按版本号整目录删除。原卡直接投影至最终画布，前景丝光只覆盖卡缘。没有提供独立反面时，侧转退场不能描述成完整正背面展示。

私有工程脚本含项目路径、裁切与角色锚点；它们不是通用SDK。新主题先重建资产与需求映射，再复用方法。
