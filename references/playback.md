# 播放问题诊断

区分四种问题：源素材内容错；本地合成几何/遮罩错；编码文件错；播放器解码或显示错。截图只能定位症状，不能证明原因。

优先使用可用的浏览器插件/专用能力查看审片页，不为浏览器操作默认调用系统桌面自动化。先区分导航权限错误与视频播放错误：若工具策略明确阻止file://或某个页面，记录限制并提供本地文件入口；不能换端口、转发、另一浏览器或间接调用绕过。逐帧检查可以继续，但正常速度播放状态仍为未验证，不能因联系表完整而勾选通过。

1. 锁定用户实际打开的文件、版本与时刻。拿不到文件名先查最相关交付，但说明范围。
2. 全解码并检查帧数、PTS间隔和尺寸；不要只读容器时长或看ffmpeg返回0。
3. 对问题前后逐帧抽图，尤其翻转经过侧面和主体消失附近。低分辨率联系表用于定位，大块破图看全帧，普通锯齿看原尺寸边缘。相同帧哈希可能是有意停留，不自动称缺帧。
4. 如本机支持，比较软件与指定硬件解码的像素结果。先确认日志确实使用硬件，不能把自动回退误记为硬解通过。两者一致只证明该机器/路径结果一致，不证明用户播放器正常。
5. 编码/兼容性疑点可新建无B帧、较少参考帧或全I帧版本供复测；保留尺寸/时间轴，重新检查体积与画质。全I帧只是诊断/兼容候选，不是根因证明。
6. 用户端仍异常时，对照相同文件在软解、另一个播放器或目标客户端。报告“已检查什么、发现什么、哪些尚未复现”，不直接归咎硬件，不将用户截图视为不存在的问题。

历史案例：八条视频的软件与本机D3D11VA帧MD5一致、PTS连续；用户截图有阶梯破图，未在抽帧复现。后续采用全I帧Baseline，体积约1.2–3.9MB；用户端是否解决仍未获得确认。不要将其标成已根治。
