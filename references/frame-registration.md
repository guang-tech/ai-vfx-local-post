# 卡面与光框配准

用于原卡与纯光效初次合成、方向适配、以及“边框和卡不齐”的反馈。先锁定当前主题的原卡尺寸、中心和动作，再测光框；不要为迁就生成光框擅改原卡比例或主体展示大小。

## 测量什么

在同一单侧输出坐标系登记原卡四边、四角、中心与宽高比。生成源另记原生尺寸、光框实测边界、测量帧和证据。测的是贴边的光核或持续框，不是最外层爆发粒子，也不是整个黑色占位范围。流动丝光不必每个发光像素都落在矩形直线上。

对登场到位、爆发峰值、展示停留、翻转中段及空框尾段逐段检查：

1. 标出原卡目标四边，叠看同一时刻的真实光效。记录左右上下的有符号误差、中心偏差及比例差。
2. 将“计划坐标”“配置投影坐标”和“实际帧测量”分开。用同一公式计算配置和预期再比较，只能证明公式自洽，不能充当画面测量。
3. 分辨中心偏移、整体尺寸偏差、长宽比不符和随时间漂移。一次整体等比缩放不能同时解决比例不符的四边。
4. 容差由画布、光核粗细和视觉目标确定并记录，不把某次2像素或某张卡尺寸写成所有项目的标准。

使用 `scripts/fx_geometry.py` 审核已测量的逐帧边界；输入和报告均保存在主题目录。该脚本要求明确坐标单位、容差和证据引用，不负责检测像素，也不作视觉放行。

输入结构见[测量示例](../assets/frame-registration.example.json)。示例是格式说明，不是现场测量证据；替换样本、帧号、容差和证据引用后运行：

```powershell
python "<skill>/scripts/fx_geometry.py" --input "<theme>/07_checks/measured-frames.json" --report "<theme>/07_checks/frame-registration-report.json"
```

退出码0表示输入样本的数值通过，1表示有边界超差，2表示输入或文件错误。报告不验证证据文件内容，也不证明未采样帧通过；实际图像和阶段覆盖须人工复核。

## 修正选择

- 平移和整体等比缩放能解决时，优先使用；卡面与附着光效仍共享后续翻转变换。
- 长宽比不符时先判断源片能否拆成独立光效层。仅在中心为空、交叠区稀疏、角部与光带可完整保留时，可以对独立层等比缩放后刚性平移。重叠区须检查双影、亮度堆积、接缝和纹理跳变；这是有条件的本地修补，不是通用“挤窄边框”算法。
- 连续环带、角色或大量粒子跨越分层区，或源几何随时间漂移时，分层修补可能破坏形态；改用适配源，必要时准备具体重新生成方案及预算。未解决前不凭文件规格PASS交付。

保持每个独立纹理层X/Y等比；不能压扁宽云气、网格挤压光带，或裁掉旧框后冒称重新生成。若改变前后层遮挡，另查卡面是否吃掉爆发和光环。局部改动后保留原源片与原时间采样，除非反馈也要求改节奏。

## 放行证据

至少保留同一帧前后对比、带四边标记的测量帧、纯光效尾段和编码后抽帧；按本次范围再核对正常速度播放。卡面内部原像素、配色、时间轴和不受影响媒体分别验证。几何、技术、逐帧、正常速度、目标客户端与用户认可各有状态。

近期匿名排错案例：首版高卡光框左右各宽出约28像素，上下约缩入13像素；编卡左右各宽出约14像素。原来中心对齐仍被用户指出错位，说明仅检查中心不足。修正版采用独立光效层定位，原卡和包装保留；整理时仍待用户审看。这个案例提供的是测量与修订经验，不是已获认可的美术基线；具体坐标、融合宽度不作为默认值。
